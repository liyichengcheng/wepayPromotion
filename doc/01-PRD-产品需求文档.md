## 一、产品概述

### 1.1 产品定位
一款基于微信小程序的付费文章阅读产品，核心模式为"预览 + 付费解锁 + 分享返佣"，通过阶梯定价和分销激励实现病毒式增长。

### 1.2 核心价值
- **对作者/内容方**：优质内容变现，自带传播属性
- **对读者**：先尝后买，付费即可获得完整内容
- **对分享者**：分享即赚钱，低门槛参与分销

### 1.3 目标用户
- **内容消费者**：愿意为优质深度文章付费的微信用户
- **内容分享者/分销员**：有一定社交资源、愿意转发赚钱的用户
- **内容运营方**：平台管理员，负责文章上架和数据监控

## 四、核心用户旅程

### 4.1 读者购买旅程
1. 进入小程序 → 浏览文章列表
2. 点击文章 → 预览第1页
3. 下滑查看更多 → 弹出付费解锁提示
4. 点击"立即解锁" → 确认价格 → 微信支付
5. 支付成功 → 自动解锁全文
6. 提示"分享赚30%" → 生成分享链接

### 4.2 分享者返佣旅程
1. 已购用户 → 点击"分享赚钱"
2. 生成专属分享卡片/链接
3. 分享给微信好友/群
4. 好友通过链接进入 → 自动绑定上下级关系
5. 好友完成支付 → 分享者获得返佣（实时到账）
6. 返佣金额 ≥ 提现门槛 → 可申请提现

## 五、关键业务规则

### 5.1 阶梯定价规则
- **基础价**：6元
- **起始人数**：前1000名支付用户均为6元
- **涨价规则**：支付用户数每增加10000人，价格上涨1元
- **价格上限**：20元封顶
- **可配置项**：基础价、起始人数阈值、每档人数、每档涨幅、价格上限均可在后台配置

**定价示例**：
| 累计支付人数 | 单价 |
|-------------|------|
| 1 - 1,000 | ¥6 |
| 1,001 - 11,000 | ¥7 |
| 11,001 - 21,000 | ¥8 |
| 21,001 - 31,000 | ¥9 |
| ... | ... |
| 141,001 - 151,000 | ¥20 |
| 151,001+ | ¥20（封顶） |

### 5.2 返佣规则
- **返佣比例**：订单实付金额的 30%
- **最低返佣**：每笔返佣不低于 2 元
- **返佣触发**：被邀请人支付成功且订单无退款
- **返佣到账**：支付成功后实时到账分享者钱包
- **关系绑定**：通过分享链接首次进入小程序的用户，与分享者绑定上下级关系
- **绑定有效期**：永久绑定（可配置）
- **防作弊**：同一设备/同一微信账号自购不返佣

**返佣计算示例**：
| 订单实付 | 30% 计算 | 实际返佣 | 说明 |
|---------|---------|---------|------|
| ¥6 | ¥1.8 | ¥2.0 | 低于最低2元，按2元计 |
| ¥7 | ¥2.1 | ¥2.1 | 高于2元，按30%计 |
| ¥10 | ¥3.0 | ¥3.0 | 按30%计 |
| ¥20 | ¥6.0 | ¥6.0 | 按30%计 |

### 5.3 防截图规则
- 小程序端开启 **禁止截屏** 能力（wx.setVisualEffectOnCapture / 企业级能力）
- Android 端：设置 FLAG_SECURE 防止截图
- iOS 端：截屏后弹出警告提示
- 录屏检测：检测到录屏时模糊内容
- 重要：微信小程序对防截图的支持有限，需采用多层防护策略（详见 04-防截图方案.md）

## 七、非功能需求

### 7.1 性能
- 文章首屏加载 < 1.5s
- 支付接口响应 < 2s
- 支持 1000+ 并发支付

### 7.2 安全
- 支付签名校验，防止篡改
- 防刷单：同一用户/设备限购检测
- 接口防重放：订单号幂等
- 返佣计算防并发：分布式锁

### 7.3 合规
- 分销层级仅限一级（直接邀请），不涉及多级分销
- 用户隐私协议和授权说明
- 支付订单可开具发票（按需）
