
# 页面交互说明文档

**版本**：v1.0  
**日期**：2026-07-24  
**关联原型**：`prototype/index.html`

## 一、页面导航架构

```
首页/文章列表 (page-list)
    ├─→ 文章详情-预览模式 (page-detail-preview)
    │       ├─→ 支付确认 (page-pay)
    │       │       └─→ 支付成功 (page-pay-success)
    │       │               └─→ 文章详情-已购模式 (page-detail-paid)
    │       │
    │       └─→ 文章详情-已购模式 (page-detail-paid)
    │               └─→ 分享成功弹窗
    │
    └─→ 个人中心 (page-my)
            ├─→ 我的订单弹窗
            ├─→ 我的佣金弹窗
            └─→ 设置弹窗
```

## 二、页面交互详解

### 2.1 文章列表页 (page-list)

**页面路径**：`/pages/index/index`  
**原型位置**：`#page-list`

#### 页面元素

| 元素 | 类型 | 交互说明 |
|------|------|---------|
| 导航栏标题 | 静态 | 显示"文章列表" |
| 文章卡片 | 可点击 | 点击进入文章详情-预览模式 |
| 文章封面图 | 静态 | 渐变色背景，显示文章标题 |
| 文章标题 | 静态 | 黑色加粗字体 |
| 预览摘要 | 静态 | 灰色小字，显示前50字 |
| 当前价格 | 动态 | 红色字体，实时计算显示 |
| 购买人数 | 动态 | 灰色小字，显示累计付费人数 |
| 定价规则配置区 | 静态 | 展示当前定价参数配置 |

#### 交互流程

```
用户进入页面
    ↓
加载文章列表数据（模拟856人购买）
    ↓
显示文章卡片（价格¥6，已有856人购买）
    ↓
用户点击卡片
    ↓
跳转至文章详情-预览模式
```

#### 定价规则展示

| 参数 | 当前值 | 交互 |
|------|--------|------|
| 基础价格 | ¥6 | 静态展示 |
| 前N名用户 | 1000人 | 静态展示 |
| 每增人数 | +10000人 | 静态展示 |
| 涨价幅度 | +¥1 | 静态展示 |
| 价格上限 | ¥20 | 静态展示 |

### 2.3 支付确认页 (page-pay)

**页面路径**：`/pages/pay/confirm`  
**原型位置**：`#page-pay`

#### 页面元素

| 元素 | 类型 | 交互说明 |
|------|------|---------|
| 返回按钮 | 可点击 | 返回文章详情-预览模式 |
| 导航栏标题 | 静态 | 显示"确认支付" |
| 商品名称 | 静态 | 显示文章标题 |
| 支付金额 | 动态 | 红色大字体显示 |
| 支付方式 | 静态 | 显示"微信支付" |
| 返佣提示区 | 静态 | 黄色背景 |
| 底部合计栏 | 静态 | 固定底部 |
| 确认支付按钮 | 可点击 | 模拟支付，跳转至支付成功页 |

#### 交互流程

```
用户进入页面
    ↓
显示订单信息（商品名、金额、支付方式）
    ↓
用户确认信息无误
    ↓
点击"确认支付"
    ↓
调用 wx.requestPayment
    ↓
支付成功 → 跳转至支付成功页
    ↓
支付失败 → 显示失败提示，可重试
```

#### 支付参数

```javascript
wx.requestPayment({
  timeStamp: String(Date.now()),
  nonceStr: '随机字符串',
  package: 'prepay_id=微信返回的预支付ID',
  signType: 'MD5',
  paySign: '签名',
  success: () => { /* 支付成功 */ },
  fail: () => { /* 支付失败 */ }
})
```

    │                              │

    │                              │

## 四、分享返佣交互流程

### 4.1 分享者视角

```
已购用户进入文章详情-已购模式
    ↓
点击"分享赚佣金"按钮
    ↓
生成专属分享链接（携带用户ID）
    ↓
弹出分享成功弹窗
    ↓
用户复制链接或使用微信分享
    ↓
分享给微信好友/群
    ↓
好友通过链接进入
    ↓
好友完成支付
    ↓
分享者获得返佣（实时到账）
    ↓
发送服务通知："您的好友xxx完成支付，您获得返佣¥x.xx"
```

### 4.2 被分享者视角

```
用户通过分享链接进入小程序
    ↓
系统检测是否为新用户
    ↓
若是新用户，自动绑定上级关系
    ↓
进入文章详情-预览模式
    ↓
显示文章预览内容
    ↓
用户完成支付
    ↓
上级分享者获得返佣
    ↓
用户解锁全文
```

### 4.3 分享链接格式

```
/pages/article/detail?id=1&inviter=10001
```

| 参数 | 说明 |
|------|------|
| id | 文章ID |
| inviter | 邀请人用户ID |

## 七、异常场景处理

### 7.1 网络异常

```
请求失败
    ↓
显示错误提示
    ↓
提供重试按钮
    ↓
用户点击重试 → 重新请求
```

### 7.2 支付失败

```
wx.requestPayment fail
    ↓
显示支付失败提示
    ↓
提供重试按钮
    ↓
用户点击重试 → 重新支付
```

### 7.3 登录失效

```
请求返回登录失效
    ↓
自动跳转至登录页
    ↓
用户完成登录
    ↓
自动跳转回原页面
```
