## 一、阶梯定价机制

### 1.1 定价公式

```
当前单价 = min(基础价 + floor(max(0, 累计支付人数 - 起始人数阈值) / 每档人数) * 每档涨幅, 价格上限)
```

**默认参数**：
| 参数 | 默认值 | 说明 |
|------|--------|------|
| basePrice（基础价） | 6 | 前 N 名用户的价格 |
| threshold（起始阈值） | 1000 | 多少人以内是基础价 |
| stepUsers（每档人数） | 10000 | 每增加多少人涨一次价 |
| stepAmount（每档涨幅） | 1 | 每次涨多少钱 |
| maxPrice（价格上限） | 20 | 最高价格 |

### 1.2 定价表（默认参数下）

| 累计支付人数区间 | 单价 | 该档人数 |
|-----------------|------|---------|
| 1 ~ 1,000 | ¥6 | 1,000 |
| 1,001 ~ 11,000 | ¥7 | 10,000 |
| 11,001 ~ 21,000 | ¥8 | 10,000 |
| 21,001 ~ 31,000 | ¥9 | 10,000 |
| 31,001 ~ 41,000 | ¥10 | 10,000 |
| 41,001 ~ 51,000 | ¥11 | 10,000 |
| 51,001 ~ 61,000 | ¥12 | 10,000 |
| 61,001 ~ 71,000 | ¥13 | 10,000 |
| 71,001 ~ 81,000 | ¥14 | 10,000 |
| 81,001 ~ 91,000 | ¥15 | 10,000 |
| 91,001 ~ 101,000 | ¥16 | 10,000 |
| 101,001 ~ 111,000 | ¥17 | 10,000 |
| 111,001 ~ 121,000 | ¥18 | 10,000 |
| 121,001 ~ 131,000 | ¥19 | 10,000 |
| 131,001 ~ 141,000 | ¥20 | 10,000 |
| 141,001 ~ 151,000 | ¥20 | 10,000 |
| 151,001+ | ¥20 | 封顶 |

> 注意：第14档（131,001~141,000）已经达到20元上限，之后维持20元不变。

### 1.3 价格展示时点
- 用户进入文章详情页时，展示当前价格
- 价格以**下单时**的价格为准，支付过程中价格锁定
- 若用户停留在页面较久，下次操作时刷新价格

### 1.4 并发处理
- 高并发下可能出现"显示价格与实际下单价格不一致"的情况
- **处理原则**：以服务端下单时计算的价格为准，前端展示价格仅作参考
- 下单时若价格有变动（涨了），返回最新价格让用户确认
- 使用乐观锁/原子计数器保证累计人数的准确性

### 1.5 后台配置
所有参数支持在管理后台动态配置，配置即时生效：
- 基础价 basePrice
- 起始阈值 threshold
- 每档人数 stepUsers
- 每档涨幅 stepAmount
- 价格上限 maxPrice
- 可按单篇文章单独配置定价策略

## 二、分享返佣机制

### 2.1 返佣规则

| 规则项 | 取值 | 说明 |
|--------|------|------|
| 返佣比例 | 30% | 订单实付金额的30% |
| 最低返佣 | ¥2 | 每笔返佣不低于2元 |
| 返佣层级 | 1级 | 仅直接邀请人获得返佣 |
| 到账时机 | 支付成功后实时到账 | 无冻结期（可配置） |
| 关系绑定 | 首次进入永久绑定 | 可配置有效期 |

### 2.2 返佣计算公式

```
返佣金额 = max(订单实付金额 * 返佣比例, 最低返佣金额)
```

**各价位返佣明细**：
| 订单实付 | 30% 计算值 | 实际返佣 | 备注 |
|---------|-----------|---------|------|
| ¥6.00 | ¥1.80 | ¥2.00 | 低于最低2元，补足 |
| ¥7.00 | ¥2.10 | ¥2.10 | 正常比例 |
| ¥8.00 | ¥2.40 | ¥2.40 | 正常比例 |
| ¥9.00 | ¥2.70 | ¥2.70 | 正常比例 |
| ¥10.00 | ¥3.00 | ¥3.00 | 正常比例 |
| ¥15.00 | ¥4.50 | ¥4.50 | 正常比例 |
| ¥20.00 | ¥6.00 | ¥6.00 | 正常比例 |

### 2.3 上下级关系绑定

#### 绑定逻辑
1. 用户 A 生成专属分享链接（携带 A 的 inviteCode）
2. 用户 B 通过 A 的分享链接进入小程序
3. 系统检测 B 是否为新用户（无上级且无支付记录）
4. 若是新用户，自动绑定 B 的上级为 A
5. 绑定后永久有效（不可更改，除非后台手动调整）

#### 绑定优先级
- **首次绑定优先**：以第一次通过谁的链接进入为准
- 已绑定用户点击他人分享链接，不改变上下级关系
- 未绑定用户多次点击不同链接，以第一次为准

#### 分享链接格式
```
/pages/article/detail?id=文章ID&invite=邀请码
```

邀请码：用户唯一标识的短码（6位字母数字）

### 2.4 返佣触发流程

```
用户B支付成功
    ↓
查询B的上级邀请人A
    ↓
计算返佣金额 = max(实付 * 30%, 2元)
    ↓
创建返佣记录（状态：待结算）
    ↓
A的钱包余额增加
    ↓
发送服务通知："您的好友xxx完成支付，您获得返佣¥x.xx"
    ↓
返佣记录状态更新为：已到账
```

### 2.5 退款处理
- 若订单发生全额退款，已发放的返佣需扣回
- 扣回顺序：先扣待结算金额，再扣可用余额
- 若余额不足，记为负数，后续返佣优先抵扣
- 部分退款按比例扣减返佣

### 2.6 防作弊规则

| 作弊场景 | 检测规则 | 处理方式 |
|---------|---------|---------|
| 自购自返 | 邀请人与下单人 openid 相同 | 不发放返佣 |
| 同设备多账号 | 同一设备多个微信账号互邀 | 设备指纹匹配，标记可疑 |
| 小额刷单 | 同一邀请人短时间内大量小额订单 | 风控审核，延迟结算 |
| 异常邀请 | 短时间邀请人数突增（如 >100人/小时） | 触发人工审核 |
| 退款套利 | 支付后立即退款，套取返佣 | 设置返佣冻结期（可选） |

## 三、钱包与提现机制

### 3.1 钱包账户
- **可用余额**：可提现的金额
- **累计收益**：历史总返佣（只增不减，用于展示）
- **待结算**：已产生但尚未到结算时间的返佣（MVP 阶段无冻结期，可省略）

### 3.2 提现规则
- **提现门槛**：最低提现 10 元（可配置）
- **提现方式**：微信零钱（企业付款到零钱）
- **到账时间**：审核通过后 1-3 个工作日（MVP 可设为自动审核实时到账）
- **提现手续费**：暂无（可配置，如 1% 手续费）
- **提现频率**：每日最多 3 次

### 3.3 提现流程
```
用户发起提现申请
    ↓
校验余额 ≥ 最低提现额
    ↓
校验当日提现次数
    ↓
扣减可用余额（冻结）
    ↓
调用微信企业付款到零钱接口
    ↓
成功 → 提现记录状态=成功
失败 → 退回余额，状态=失败
    ↓
发送服务通知
```

## 四、关键数据表设计

### 4.1 文章定价表（article_price_config）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| article_id | bigint | 文章ID |
| base_price | decimal(10,2) | 基础价 |
| threshold | int | 起始人数阈值 |
| step_users | int | 每档人数 |
| step_amount | decimal(10,2) | 每档涨幅 |
| max_price | decimal(10,2) | 价格上限 |
| paid_count | int | 累计支付人数（冗余，用于快速计算） |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### 4.2 订单表（orders）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| order_no | varchar(32) | 订单号 |
| user_id | bigint | 购买用户ID |
| article_id | bigint | 文章ID |
| inviter_id | bigint | 邀请人ID（上级） |
| price | decimal(10,2) | 下单时单价 |
| pay_amount | decimal(10,2) | 实付金额 |
| commission_amount | decimal(10,2) | 返佣金额 |
| status | tinyint | 订单状态：0待支付 1已支付 2已退款 |
| pay_time | datetime | 支付时间 |
| created_at | datetime | 创建时间 |

### 4.3 用户关系表（user_relation）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| user_id | bigint | 用户ID |
| inviter_id | bigint | 邀请人ID |
| bind_time | datetime | 绑定时间 |
| bind_source | tinyint | 绑定来源：1分享链接 2海报 3手动输入 |

### 4.4 返佣记录表（commission）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |

| order_id | bigint | 关联订单ID |

| status | tinyint | 状态：0待结算 1已到账 2已扣回 |

### 4.5 钱包表（wallet）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| user_id | bigint | 用户ID |

| total_income | decimal(10,2) | 累计收益 |
| total_withdraw | decimal(10,2) | 累计提现 |
| updated_at | datetime | 更新时间 |

### 4.6 提现记录表（withdraw）
| 字段 | 类型 | 说明 |
|------|------|------|

| user_id | bigint | 用户ID |
| amount | decimal(10,2) | 提现金额 |
| fee | decimal(10,2) | 手续费 |
| actual_amount | decimal(10,2) | 实际到账 |
| status | tinyint | 状态：0待审核 1处理中 2成功 3失败 |
| withdraw_no | varchar(32) | 提现单号 |
