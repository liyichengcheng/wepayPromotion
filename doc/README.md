## Axure PR9 原型说明

### 关于格式说明

由于 Axure PR9 的 `.rp` 文件是专有二进制格式，无法通过文本写入工具直接生成。本项目采用 **HTML 交互原型**作为替代方案，具备以下特点：

| 特性 | Axure PR9 | HTML原型 |
|------|----------|---------|
| 文件格式 | 二进制(.rp) | 文本(.html) |
| 多页面导航 | ✅ | ✅ |
| 组件库 | ✅ | ✅（自定义） |
| 交互逻辑 | ✅ | ✅（JavaScript） |
| 弹窗/模态框 | ✅ | ✅ |
| 条件显示 | ✅ | ✅ |
| 浏览器预览 | ✅（需导出） | ✅（直接打开） |
| 版本控制 | ❌ | ✅ |
| 团队协作 | ✅ | ⚠️（有限） |

### 原型页面覆盖

| PRD页面 | 原型实现 | 状态 |
|---------|---------|------|
| 首页/文章列表 | `#page-list` | ✅ |
| 文章详情（预览模式） | `#page-detail-preview` | ✅ |
| 文章详情（已购模式） | `#page-detail-paid` | ✅ |
| 支付确认 | `#page-pay` | ✅ |
| 支付成功 | `#page-pay-success` | ✅ |
| 个人中心 | `#page-my` | ✅ |
| 分享中心 | - | ⏳ 待实现 |
| 我的钱包 | - | ⏳ 待实现 |
| 提现页面 | - | ⏳ 待实现 |

### 在 Axure PR9 中重建原型

如需在 Axure PR9 中重建原型，请按照以下步骤操作：

#### 1. 创建页面

| 页面名称 | Axure页面名称 | 尺寸 |
|---------|--------------|------|
| 文章列表 | page-list | 375×812 |
| 文章详情-预览 | page-detail-preview | 375×812 |
| 文章详情-已购 | page-detail-paid | 375×812 |
| 支付确认 | page-pay | 375×812 |
| 支付成功 | page-pay-success | 375×812 |
| 个人中心 | page-my | 375×812 |

#### 2. 创建组件

| 组件名称 | 类型 | 说明 |
|---------|------|------|
| NavBar | 动态面板 | 导航栏（返回按钮+标题） |
| ArticleCard | 动态面板 | 文章卡片（封面+标题+价格） |
| PriceTag | 动态面板 | 价格标签（单位+数值） |
| BuyButton | 按钮 | 购买按钮（渐变色） |
| PreviewMask | 动态面板 | 预览结束遮罩 |
| CommissionInfo | 动态面板 | 返佣提示区（黄色背景） |
| TabBar | 动态面板 | 底部导航栏 |
| Modal | 动态面板 | 弹窗（标题+内容+按钮） |
| ScreenshotAlert | 动态面板 | 防截图警告（全屏覆盖） |

#### 3. 设置交互

| 交互场景 | 触发条件 | 目标 | 动作 |
|---------|---------|------|------|
| 进入文章详情 | 点击ArticleCard | page-detail-preview | 打开页面 |
| 返回列表 | 点击NavBar返回按钮 | page-list | 返回页面 |
| 跳转支付 | 点击BuyButton | page-pay | 打开页面 |
| 支付成功 | 点击确认支付按钮 | page-pay-success | 打开页面 |
| 查看全文 | 点击查看全文按钮 | page-detail-paid | 打开页面 |
| 分享成功 | 点击分享按钮 | Modal | 显示弹窗 |
| 关闭弹窗 | 点击确定按钮 | Modal | 隐藏弹窗 |
| 截图警告 | 触发onUserCaptureScreen | ScreenshotAlert | 显示2秒 |

#### 4. 设置变量

| 变量名称 | 类型 | 默认值 | 用途 |
|---------|------|--------|------|
| currentPrice | Number | 6 | 当前价格 |
| paidUserCount | Number | 856 | 累计付费人数 |
| userId | Number | 0 | 当前用户ID |
| isPaid | Boolean | false | 是否已购买 |
| showScreenshotAlert | Boolean | false | 是否显示截图警告 |

#### 5. 设置条件逻辑

**文章详情页面显示逻辑**：

```
如果 isPaid = true：
    显示"已购买"标签
    显示完整文章内容
    隐藏预览遮罩
    显示分享卡片
否则：
    显示当前价格
    显示预览内容
    显示预览遮罩
    显示购买按钮
```

**价格计算逻辑**：

```
如果 paidUserCount <= 1000：
    currentPrice = 6
否则：
    currentPrice = min(6 + floor((paidUserCount - 1000) / 10000), 20)
```

**返佣计算逻辑**：

```
commission = max(currentPrice * 0.3, 2)
```
