# 付费文章小程序前端原型
路径：D:\myCode\wepayPromotion\doc\prototype2
## 功能清单
1. 文章仅开放首段预览，付费解锁全文
2. 阶梯动态定价
   - 前1000人：6元
   - 每新增1w付费用户 +1元，最高20元封顶
3. 分享返佣：实付金额30%，佣金最低保底2元
4. 前端基础防截图、防复制、禁用右键
5. 微信支付弹窗 + 分享入口

## 部署运行
直接双击 index.html 在浏览器打开预览界面
接入真实微信小程序需要：
1. 替换支付逻辑为 wx.requestPayment
2. 分享携带分发者openid用于返佣结算
3. 后端维护付费人数、阶梯价格、佣金账单
4. 小程序端使用 wx.setVisualEffectOnCapture 系统级拦截截屏
