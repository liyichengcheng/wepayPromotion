
# 防截图方案设计文档

**版本**：v1.0  
**日期**：2026-07-24  

---

## 一、概述

由于微信小程序运行在微信客户端内，受限于平台能力，完全禁止截图是不可能的。本方案采用**多层防护策略**，在可用能力范围内最大程度防止内容被截图传播。

---

## 二、可用能力分析

### 2.1 wx.setVisualEffectOnCapture（推荐）

| 特性 | 说明 |
|------|------|
| **基础库要求** | 2.12.0 及以上 |
| **能力描述** | 设置用户主动截屏时的视觉效果 |
| **效果** | 截屏图片会显示为指定效果（如黑色、模糊等） |
| **iOS支持** | ✅ 支持（系统级能力） |
| **Android支持** | ✅ 支持（部分机型） |
| **局限性** | 用户仍可通过系统录屏、第三方工具绕过 |

**使用示例**：
```javascript
wx.setVisualEffectOnCapture({
  visualEffect: 'hidden',
  success: () => {
    console.log('防截图已开启')
  },
  fail: () => {
    console.log('当前版本不支持防截图')
  }
})
```

### 2.2 wx.onUserCaptureScreen（监听截图事件）

| 特性 | 说明 |
|------|------|
| **基础库要求** | 1.4.0 及以上 |
| **能力描述** | 监听用户主动截屏事件 |
| **效果** | 用户截屏后触发回调 |
| **应用场景** | 弹出警告提示、记录日志、短暂遮挡内容 |

**使用示例**：
```javascript
wx.onUserCaptureScreen(() => {
  this.setData({ showScreenshotAlert: true })
  setTimeout(() => {
    this.setData({ showScreenshotAlert: false })
  }, 2000)
})
```

### 2.3 企业微信专属能力（企业级方案）

| 特性 | 说明 |
|------|------|
| **适用范围** | 企业微信小程序 |
| **能力描述** | 支持更严格的防截屏策略 |
| **效果** | 系统级禁止截屏、录屏 |
| **局限性** | 仅企业微信可用，不适用于普通小程序 |

## 三、多层防护策略

### 3.1 策略层次

```
┌─────────────────────────────────────────────────────────┐
│                    第1层：系统级防护                    │
│    wx.setVisualEffectOnCapture 设置截图隐藏效果         │
├─────────────────────────────────────────────────────────┤
│                    第2层：事件监听                      │
│    wx.onUserCaptureScreen 监听截图并警告                │
├─────────────────────────────────────────────────────────┤
│                    第3层：视觉混淆                      │
│    水印叠加、文字模糊、动态内容                          │
├─────────────────────────────────────────────────────────┤
│                    第4层：业务风控                      │
│    截图检测上报、异常账号标记、传播溯源                  │
└─────────────────────────────────────────────────────────┘
```

### 3.2 各层详细设计

#### 第1层：系统级防护

```javascript
Page({
  onLoad: function () {
    if (wx.setVisualEffectOnCapture) {
      wx.setVisualEffectOnCapture({
        visualEffect: 'hidden',
        success: () => {
          console.log('[防截图] 系统级防护已开启')
        },
        fail: (err) => {
          console.warn('[防截图] 系统级防护不可用:', err)
        }
      })
    }
  }
})
```

**视觉效果参数**：
| 参数值 | 效果 | 适用场景 |
|--------|------|---------|
| `hidden` | 截图显示为全黑 | 核心内容保护（推荐） |
| `blur` | 截图显示为模糊 | 轻度保护 |
| `none` | 无效果（关闭） | 测试/调试 |

#### 第2层：事件监听与警告

```javascript
Page({
  data: {
    showScreenshotAlert: false
  },
  
  onLoad: function () {
    if (wx.onUserCaptureScreen) {
      wx.onUserCaptureScreen(() => {
        this.handleScreenshot()
      })
    }
  },
  
  handleScreenshot: function () {
    this.setData({ showScreenshotAlert: true })
    
    wx.showToast({
      title: '禁止截图',
      icon: 'none',
      duration: 2000
    })
    
    setTimeout(() => {
      this.setData({ showScreenshotAlert: false })
    }, 2000)
  }
})
```

**警告UI设计**：
```html
<view class="screenshot-overlay" wx:if="{{showScreenshotAlert}}">
  <view class="screenshot-alert">
    <text class="alert-icon">⚠️</text>
    <text class="alert-text">禁止截图</text>
    <text class="alert-desc">截图内容将被隐藏</text>
  </view>
</view>
```

#### 第3层：视觉混淆

**水印叠加**：
```html
<view class="watermark">
  <text class="watermark-text">{{userInfo.nickname}}</text>
  <text class="watermark-text">{{currentTime}}</text>
</view>
```

```css
.watermark {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  pointer-events: none;
  overflow: hidden;
  z-index: 9999;
}

.watermark-text {
  position: absolute;
  font-size: 100rpx;
  color: rgba(0, 0, 0, 0.05);
  transform: rotate(-45deg);
  white-space: nowrap;
}
```

**动态内容混淆**：
- 关键数据使用动态加载
- 部分内容使用 Canvas 绘制（截图时可清空）
- 文字颜色与背景色接近，降低可读性

#### 第4层：业务风控

**截图行为上报**：
```javascript
handleScreenshot: function () {
  wx.request({
    url: '/api/risk/screenshot',
    method: 'POST',
    data: {
      userId: app.globalData.userId,
      articleId: this.data.article.id,
      timestamp: Date.now()
    }
  })
}
```

**风控规则**：
| 规则 | 条件 | 处理方式 |
|------|------|---------|
| 截图频率异常 | 1分钟内超过3次 | 暂时隐藏内容，弹出警告 |
| 连续截图 | 连续5次以上 | 记录风险等级，后台审核 |
| 传播检测 | 同一内容在多个设备出现 | 标记来源，溯源传播链 |

## 四、平台差异处理

### 4.1 iOS 平台

| 版本 | 能力支持 | 说明 |
|------|---------|------|
| iOS 13+ | ✅ `setVisualEffectOnCapture` | 系统原生支持 |
| iOS 12及以下 | ⚠️ 部分支持 | 可能需要降级方案 |

**iOS特有方案**：
- 利用 `WKWebView` 的 `allowsPictureInPictureMediaPlayback` 设置
- 使用 `UIScreen` 的截图通知

### 4.2 Android 平台

| 版本 | 能力支持 | 说明 |
|------|---------|------|
| Android 10+ | ✅ `setVisualEffectOnCapture` | 系统原生支持 |
| Android 9及以下 | ⚠️ 依赖厂商实现 | 部分机型可能无效 |

**Android特有方案**：
- 检测 `FLAG_SECURE` 标志
- 监听系统截图广播 `android.intent.action.SCREENSHOT`

### 4.3 降级方案

当 `setVisualEffectOnCapture` 不可用时：

```javascript
if (!wx.setVisualEffectOnCapture) {
  console.warn('[防截图] 当前版本不支持系统级防护，启用降级方案')
  
  this.setData({ showWatermark: true })
  
  wx.showModal({
    title: '提示',
    content: '当前版本不支持防截图，请手动保护内容安全',
    showCancel: false
  })
}
```

## 五、用户体验平衡

### 5.1 不要过度干扰

| 场景 | 处理方式 |
|------|---------|
| 首次截图 | 温和提示，不强制遮挡 |
| 多次截图 | 加强警告，短暂遮挡 |
| 频繁截图 | 限制功能，引导合规 |

### 5.2 提示文案设计

**首次截图提示**：
> ⚠️ 提醒：本文内容受版权保护，禁止截图传播

**多次截图警告**：
> ⚠️ 警告：已检测到多次截图行为，继续截图将影响阅读体验

**功能限制提示**：
> ⚠️ 已限制：检测到异常截图行为，请稍后再试

## 七、注意事项

1. **无法完全禁止**：任何防截图方案都无法完全阻止用户通过物理拍摄等方式获取内容
2. **合规性**：防截图功能仅用于保护版权内容，不得用于非法用途
3. **性能影响**：过度的视觉混淆可能影响页面性能，需合理平衡
4. **用户告知**：首次进入付费内容页面时，应明确告知用户防截图策略
5. **日志记录**：所有截图行为应记录日志，便于后续风控分析

## 八、与业务规则的配合

### 8.1 价格保护

当检测到截图行为时：
- 不影响当前用户的价格计算
- 但会记录用户风险等级

### 8.2 返佣影响

截图行为不影响返佣规则：
- 分享者的返佣不受被分享者截图行为影响
- 返佣仅与支付行为挂钩

### 8.3 内容访问

多次截图后可采取的限制：
- 临时隐藏部分内容
- 降低内容清晰度
- 要求重新验证身份
